# 바다의 신 보이스 대본 (캔디크러쉬 "Sweet! / Delicious!" 역할)

캐릭터: **바다의 신 "포세 할아버지"** — 깊고 따뜻한 할아버지 목소리, 크게 웃는 호탕한 톤. 짧고 힘 있게(0.6~1.2초), 끝을 길게 끌며 울림.
가공: 살짝 낮은 피치 + 넓은 동굴/물속 잔향 + 끝에 물방울 반짝 효과.

**결정 (2026-10-18): 캔디크러쉬처럼 언어와 상관없이 영어 대사로 통일.** 한국어 칸은 참고용.
